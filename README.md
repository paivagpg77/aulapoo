# Repositório de Aula — POO

Repositório destinado às atividades e exercícios desenvolvidos durante as aulas de **Programação Orientada a Objetos (POO)** utilizando Java.

## 📚 Conteúdos

Durante as atividades são trabalhados conceitos como:

* Classes e objetos
* Atributos e métodos
* Construtores
* Encapsulamento
* Getters e Setters
* ArrayList
* Relacionamento entre classes
* Métodos e funções
* Estruturas de repetição e decisão
* Organização de projetos Java

## 💻 Projeto

Entre os exercícios desenvolvidos está um **Sistema de Biblioteca**, com funcionalidades como:

* Cadastro de usuários
* Cadastro de livros
* Listagem de usuários
* Listagem de livros
* Empréstimo de livros
* Controle de empréstimos

## 🛠️ Tecnologias

* Java
* Programação Orientada a Objetos
* IDE de desenvolvimento Java

## 🎯 Objetivo

Praticar e aplicar os principais conceitos de **Programação Orientada a Objetos em Java** através de exercícios e pequenos sistemas.
